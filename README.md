# Mastercare 11.11 Grand Opening Menu

A responsive, bilingual beach-themed event menu with 10 food and drink items, category filters and accessible photo previews.

Live: https://romastro9.github.io/Mastercare-11.11-Menu/

## Hosting
GitHub Pages: deploy from `main`, folder `/ (root)`. No dependencies or build step.

## Editing
- `app.js`: item names, categories and photo positions.
- `style.css`: responsive layout, cream/gold/sea palette and typography.
- `assets/menu.webp`: shared beach-themed menu artwork.

Fonts: Cormorant Garamond, DM Sans and Kantumruy Pro, with system fallbacks.
